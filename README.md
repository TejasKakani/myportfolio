# Portfolio

Personal developer portfolio of Tejas Kakani, a full-stack developer.

Live site: https://tejaskakani.github.io/myportfolio

## Sections

- Hero and About
- Technologies
- Projects
- Contact
- Downloadable resume

## Tech stack

- React and Vite
- Tailwind CSS
- Motion for animations, react-scroll for navigation
- react-icons and Lucide icons

## Run locally

```bash
npm install
npm run dev
```
